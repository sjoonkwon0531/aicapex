# 동향 기록(/watch) 운영 규칙

`public/watch/entries.json` 의 `entries` 배열에 항목을 더한다. 페이지는 날짜 역순으로 그린다. `updated` 는 마지막 확인일.

항목 형식: `{date, title, body, sites[], sources[{title,url}], decision}`
- `sites`: capex, hyperscaler, google, commerce, memsim, monitor, brief 중 해당하는 것.
- `decision: true` 는 SJ 검토가 필요한 항목(사이트에는 "검토 중"으로 보임).

## 자동으로 해도 되는 것
- 원자료(회사 공시·IR, SEC, 관세청·산업부 발표, 통계 원문)로 확인한 사실을 기록에 더하기. 숫자는 원문에서 그대로.
- `public/capex/data/*` 의 자료 갱신(월간 작업 규칙대로).
- 기록 항목의 오타·링크 수정.

## SJ 결정을 받아야 하는 것 (푸시 알림으로 묻고, 승인 전에는 바꾸지 않는다)
- 시뮬레이터의 가정·모수(컨센서스 값, 회수율, 시나리오), 결론 문장, 허브의 "인용할 때" 문구.
- 브리프·칼럼의 결론이나 수치.
- 새 페이지·새 그림 추가, 사이트 구조 변경.
- 기록 항목 가운데 해석이나 전망을 담은 것(사실만 담은 항목은 자동).

## 하지 않는 것
- 투자 권유, 특정 종목의 매수·매도 판단, memsim 비공개 운용 내용의 공개.
- 확인하지 못한 숫자, 2차 보도만 있는 숫자를 사실처럼 적기(적더라도 "보도에 따르면"과 출처를 단다).
